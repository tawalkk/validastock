SCRIPT LOCAL LIMITADO

Automação legível, linha por linha.

Use comandos pequenos para coordenar ações. O editor interpreta apenas a linguagem do Pilot Local.

// rotina de exemplo
wait 1000
click 420 260
key Enter
log "Concluído"
COMANDOS DE EXEMPLO

Comece pequeno.
Evolua quando quiser.

O Pilot Local usa uma linguagem própria, com comandos explícitos e limites para repetição, espera e tamanho do script.

rotina.pilotscript
01// espera a janela terminar de abrir
02wait 1200
03click 420 260
04text "Olá, Pilot Local"
05key Enter
06log "Rotina concluída"
✓ Os scripts são processados localmente pelo aplicativo.

FEITO PARA SER CLARO

Você continua
no comando.

O Pilot Local mantém macros, fluxos e scripts no seu computador. O app não executa programas externos, não usa plugins ou Lua e não lê a memória de outros processos.
